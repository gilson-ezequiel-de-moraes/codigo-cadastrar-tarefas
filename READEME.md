Gerenciador Simples de Tarefas em Python

Um script simples em Python para cadastro e organização rápida de tarefas do dia a dia, fornecendo um feedback personalizado de acordo com o volume de atividades cadastradas.

📋 Funcionalidades

Identificação Personalizada: Solicita o nome e a cidade do usuário.

Cadastro Dinâmico: Permite definir a quantidade exata de tarefas que deseja registrar.

Listagem de Tarefas: Exibe todas as tarefas cadastradas de forma organizada.

Análise da Rotina: Gera uma mensagem personalizada com base no volume de tarefas:

0 tarefas: Informa que nenhuma tarefa foi cadastrada.

1 a 3 tarefas: Indica uma rotina leve.

Mais de 3 tarefas: Alerta para uma rotina cheia e sugere organizar prioridades.

🚀 Como Executar

Pré-requisitos

Python 3.x instalado em seu computador.

Passo a Passo

Faça o download ou copie o código para um arquivo chamado main.py (ou o nome de sua preferência).

Abra o terminal ou prompt de comando no diretório onde o arquivo está salvo.

Execute o comando:

python main.py


💻 Exemplo de Uso

Digite seu nome: Maria
Digite sua cidade: São Paulo
Quantas tarefas você vai cadastrar? 2
Digite a tarefa 1: Estudar Python
Digite a tarefa 2: Ir ao mercado

🛠️ Tecnologias Utilizadas

Python 3 (Estruturas de repetição for, condicionais if/elif/else, e manipulação de listas).
